## 保研关键节点(通用时间线,需按当年调整)

> 近几年保研名额确认及接收推免等时间有所变化,与25年的保研为09.28为开始正式录取,几乎全部同学在当天结束录取.

| 时间 | 事项 |
|------|------|
| 大一~大三 | 维持绩点、参与科研/竞赛、争取排名 |
| 大三寒假~3月 | 关注目标院校,准备简历、成绩单、个人陈述 |
| 3~5 月 | 各校**夏令营**报名开启 |
| 6~7 月 | 参加夏令营、争取「优秀营员」 |
| 8~9 月初 | **预推免**报名与考核 |
| 9 月下旬 | 教育部**推免服务系统**开放,正式填报、确认录取 |
| 9~10 月 | 完成接收 |

## 常见去向院校

如保研方向为数学、统计一类：以北大为上界，复旦为我认为的近几年上确界，专业第一如不直博，学校层次大约为南开，2-5名大约为国科大、山东大学、湖南大学等，边缘如中海洋、本校等。如有特殊情况（如好论文、编程能力很强）可以大约提升一个到半个档次，如南开→南大。



方向为计算机则保研院校去向层次在编程不错的情形下几乎与数学等同，如果无计算机科研项目、编程能力较差则会降一档，如南大→南开。



方向为经管及其他较新方向或选择直博，则可以提升一个到半个档次，如南开→南大。
