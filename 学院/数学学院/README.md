## 学院概况

欢迎来到河海大学数学学院，我将作为本项目的发起人也是数学学院的老登学长为大家介绍此院。我们先讲述数学学院的历史，hhu数院最早的前身为学校一个专门负责高数教育的系别（仅有偶尔开设的师资班），后随着时代的变迁于2000年左右独立建院，同物理系组建了理学院。理学院一直延续到2023年左右，随着数学独立建制，物理并入力学院，理学院的历史告一段落。所以从历史而言hhu的数学建院时间较短，发展时间却很长。



**学科实力上**，数学在整个第四次学科评估中似乎是C-，同我校法学院学科评估为同一水平，堪称拉完了。但是考虑到在第五次学科评估左右，随着独立建院及获得数学的博士点，且早前学科评估大部分学术成果被拿去支持水一系学科评级，我大概可以给他评一个半步b-。（注：南师、上大等学校的数学为b+，如果你从河南高考吉大数学为a-，或许都是更好的选择，虽然我当时没选）



**发展上**，数学院因hhu是工科学校而一直发展有限，但我们也不得不承认，工科学校也自有其好处，如果你足够乐于探索且有充足的信息，大可以和水利一系或者计算机的老师进行科研，会对未来的升学有一定的好处。由于刚刚独立建院不久，所以我们还姑且可以将此学院看作处在上升期，最近在搞什么华罗庚班，虽然有蹭华老名头之嫌，但是这样的特色班做好了是很有好处的，对保研的优势尤其大，考研应该也同理，可参考山大泰山学院，其中保研清北不在少数。总的来说，目前很可能在上升期，但由于数学人才一贯执行力低下，我对此期望并不算特别高；不过杨院长一向勤勉，或许会让此处有更多的发展和机会。希望她越来越好吧。



**氛围上**，数院常常是很特别的。人们大都听说过北大疯人院的传说，hhu的数院没那么奇葩，经常每个年级还是有一些大美女的，人们的精神状况也还算正常。总的来说，过去的四年中，学院内大部分老师并没有很强的科研压力，整体氛围较为轻松，但随着非升即走的引入，我也看到了一些很勤勉的年轻老师。预期未来一段时间随着经济环境的周期问题，你们将面对更加激烈的竞争。保研过程中勾心斗角并不多，可以说几乎没有，整体我们也纯粹一些，更尊重数学水平高的选手并以此为荣，由此带来的清高也导致很多数学学的不错的同学并没有什么拿得出手的科研项目。



**升学上**，我并不推荐数学保研，由于学科性质，数学系的老师往往不是很依赖于研究生的工作，甚至很多时候多的招生名额对老师来说是一种负担，这也导致在工科研究生大部分为本科生数量两倍的同时，数学院的研究生是比本科生少的。名额的减少势必使得我们希望升学时面对的竞争压力更大，这显而易见。与此同时，数学的应用属性（主要指在企业中就业）较弱，哪怕是被人吹捧的统计学实际也是蹭上互联网才就业不错，对此我建议考研可以转向其他方向，这样竞争压力会下降很多，同时也不必面对研究生的数学课程（大部分数学系同学应该学多了数学也头大）。但是请不要迷信某些人说的数学“万金油”言论，如果你要学计算机就直接去学，学人工智能就直接去学，不需要先把数学学好。所有**“先学好数学打基础，再去做其他的”**，这样的言论都是曲折的，如果你想做好人工智能，直接去做就好了，数学学需要的就可以了。想做什么就做什么，别总想着要先准备好某某才能做，“干中学”是有道理的。



**专业上**，数院的两个专业之间差别不大，起码我在时并不大，只有几门课程的区别，而且想学也可以选，不需要多交学费。不过需要说明的是保研名额为专业内分配，可以考虑竞争激烈程度对专业进行选择（我当时因为前三名中两个人选了应数落荒而逃到计算，使我在绩点上的压力少了很多）。
