# 校园信息共享 📚

> 一个由学生共同维护、面向在校生与新生的信息共享项目。
> 目标:**减小信息差**——把就业去向、保研/考研关键节点、转专业流程、考试资料和真实的个人经验沉淀下来,让后来人少走弯路。**同时，这可能是你的第一个GitHub项目，让我们从这里开始。**

## 写在前面

本项目的核心想法有三个。

**第一,让大家的大学生活更加轻松。** 无论是提高分数、锻炼能力,还是顺利通过考试,我们都希望能在这些方面为大家提供一些帮助。

**第二,减少信息差,尽可能摆脱对某些「圈子」的依赖。** 上大学以来,我常常发现:那些和学长学姐关系更好的同学,更容易拿到往年的期末试卷,更清楚哪门课容易拿高分,也更知道哪些课是真正有用的。我们并不排斥与学长学姐建立良好的关系,但也不得不承认,这样的交流往往重复而低效,还伴随着某种信息壁垒。我希望能打破这些壁垒,让问题更直接地被解决。(很多时候我们需要别人的帮助。如果可以,尽量和你认可的人建立起良好的关系——这在很多时候会很有帮助,也会让人生更加丰富多彩。)

**第三,我希望借这个机会,传播一些自己的观念,分享一些人生经验,** 让大家面对大学生活时少一些迷茫、焦虑和内耗,多一些从容和把握。

此外,我始终相信:充分的开源与交流,对世界上绝大多数事情都是有益的。希望通过这样的开源和分享,能为大家提供一些我力所能及的帮助。

---

抱怨大环境听起来会有点像不得志的老登。但面对现状,我们最先、也最重要的一步,是先看清自己所处的处境。

学弟学妹们,你们应当知道:找不到工作并不是你们的错,而是时代转型带来的岗位减少;你们应当知道,大学的学习看似越来越难,但 AI 已经可以帮我们应付绝大多数问题——**让 AI 成为我们的朋友,就像时间终将成为我们的朋友那样**;你们应当知道,大学时间无比宝贵,我曾把它浪费在许多无聊的事情上,希望你们不要重蹈覆辙,我不建议把大量时间花在对未来毫无意义的家教上,哪怕你常常缺钱。

我们也应当知道,我们面对的是所有人都不曾面对过的时代,身处前人未曾经历的处境,解决着从没有人解决过的问题。**我们当然会迷茫,但不要放弃找寻,那正是大学的核心要义。** 希望你能在一段迷茫的时光里慢慢找到方向;但如果最终没有找到,那也很正常。此外，由于相差四年的代际，再加上可能大家要接着研究生深造三年左右的时间，四年或七年后你们或将面对一个再次蓬勃发展的时代，我希望它快些到来。期待在不远的未来，人们能再次在一起欢歌舞蹈，为快速的发展而喜悦，享受着时代进步的成果。

## 🤝 如何参与

这个项目靠大家一起填充才有价值。无论你是即将毕业的学长学姐,还是想分享经验的在校生:

1. 阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 了解贡献方式与规范
2. 从 [templates/](templates/README.md) 复制对应的模板
3. 填好后通过 Pull Request 或 Issue 提交

**不会用 Git 也没关系**——直接提一个 Issue,把内容贴上来,维护者会帮你整理。

## ⚠️ 重要原则

- **保护隐私**:不写真实姓名/学号,不泄露他人信息(详见 CONTRIBUTING)
- **尊重版权**:只分享个人笔记与经验,**不上传受版权保护的教材、付费课程、真题原件**
- **信息有时效**:政策与节点每年可能变化,请注意文件标注的年份,以学校官方通知为准
